# Credit-Card-Fraud-Detection
Developed a Machine Learning-based Credit Card Fraud Detection system using the Kaggle dataset of 284,807 transactions. The project addresses severe class imbalance using techniques such as class weighting and SMOTE and evaluates multiple models using precision, recall, F1-score, ROC-AUC, and PR-AUC. Random Forest was selected as the final model.
